# 🏪 Hệ Thống Quản Lý Siêu Thị Mini (Swing GUI)

Đây là đồ án môn học **Lập trình hướng đối tượng (OOP)**. Ứng dụng được xây dựng bằng ngôn ngữ Java, sử dụng thư viện Swing để thiết kế giao diện hiện đại và chuyên nghiệp.

## 🌟 Tính năng chính

- **Bán hàng (POS):** Giao diện bán hàng chuyên nghiệp, hỗ trợ quét mã, tính tiền, áp dụng giảm giá khách hàng và in hóa đơn.
- **Quản lý Sản phẩm:** Theo dõi tồn kho, giá bán, ngày nhập và hạn sử dụng.
- **Quản lý Nhân viên:** Phân quyền hệ thống (Admin/Staff), quản lý thông tin và lương thưởng.
- **Quản lý Khách hàng:** Hệ thống tích điểm và phân hạng thành viên (Thân thiết, Bạc, Vàng).
- **Quản lý Nhập hàng:** Theo dõi lịch sử nhập hàng từ các nhà cung cấp.
- **Báo cáo & Thống kê:** Biểu đồ doanh thu, thống kê sản phẩm bán chạy và báo cáo tồn kho.

## 🛠 Công nghệ sử dụng

- **Ngôn ngữ:** Java 17
- **Giao diện:** Java Swing (Custom UI Components)
- **Lưu trữ dữ liệu:** JSON (Sử dụng thư viện Gson)
- **Kiến trúc:** Object-Oriented Programming (OOP) với các Design Patterns (Factory, Strategy, Observer).

## 🚀 Hướng dẫn cài đặt và chạy

### 1. Yêu cầu hệ thống
- Đã cài đặt **Java JDK 17** hoặc mới hơn.

### 2. Cách đóng gói (Build)
Chạy file `build-jar.bat` để biên dịch mã nguồn và tạo file thực thi:
```powershell
./build-jar.bat
```

### 3. Cách chạy ứng dụng
Sau khi build thành công, chạy file `run.bat` hoặc double-click vào `SieuThiMini.jar`:
```powershell
./run.bat
```
